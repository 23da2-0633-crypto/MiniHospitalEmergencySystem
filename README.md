\# Mini Hospital Emergency Management System



\## Project Description



This project is a Mini Hospital Emergency Management System developed using Java and Data Structures.



The system manages patient records, emergency patients, treatment history, and patient visit history.



\## Data Structures Used



\### 1. Binary Search Tree (BST)



Used to store and manage patient records.



\* Insert patient

\* Search patient by ID

\* Delete patient

\* Display patients in ascending order



\### 2. Queue



Used to manage emergency patients.



The Queue follows the FIFO (First In, First Out) principle.



\* Add patient to emergency queue

\* Treat the next patient

\* Display waiting patients



\### 3. Stack



Used to store treatment history.



The Stack follows the LIFO (Last In, First Out) principle.



\* Add completed treatment

\* Display treatment history



\### 4. Singly Linked List



Used to manage patient visit history.



\* Add visit

\* Search visit

\* Remove visit

\* Display visit history
